# Esprit-PW-2A4-2027-CarthageSante





\# Carthage Santé – Plateforme web de santé familiale



\## Overview

Projet réalisé dans le cadre du module Projet Technologies Web 2A à Esprit School of Engineering (année universitaire 2026-2027).



Carthage Santé est un carnet de santé familial connecté : chaque famille suit la santé de tous ses membres (vaccins, rendez-vous, médicaments, mesures) et accède rapidement aux services de proximité (médecins, pharmacies, gardes).



\## Features

\- Espace familial avec plusieurs profils et carnet de santé numérique

\- Rappels et calendrier (vaccins, contrôles, rendez-vous)

\- Réservation de rendez-vous chez les médecins partenaires

\- Pharmacies partenaires et pharmacie familiale

\- Assistant IA d'orientation (sans diagnostic)

\- Espaces dédiés : client, médecin, pharmacien, administrateur



\## Tech Stack

\### Frontend

\- HTML5, CSS3, JavaScript

\- Template Front Office : Clinic

\- Template Back Office : AdminLTE 4



\### Backend

\- PHP 8 (POO, architecture MVC)

\- PDO + MySQL



\## Architecture

Architecture MVC : `Controllers/`, `Models/`, `Views/`

(avec `includes/` pour les éléments communs et `assets/` pour CSS, images et scripts).
